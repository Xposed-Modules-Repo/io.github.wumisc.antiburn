# 防止烧屏 App 启动图标设计 Brief（v2.0）

## 任务
- 主题：防止烧屏（anti screen burn-in）Android LSPosed 模块的启动器图标
- 交付环境：mobile_direct（本地 Brief，无 Canvas）
- 路线：pure-image，单张 1:1 成品位图
- 商品：无实体商品；核心对象 = 软件功能本身（屏幕像素防烧屏保护）

## 用途与传播目标
- 用途：Android launcher icon（替换工程内原 24dp 白色盾牌 vector）
- 第一眼：一个"保护盾牌 + 手机屏幕像素"的图形，明确传达"屏幕防护"
- 第二眼：盾牌内的屏幕上有像素点阵、底部像素淡出，暗示"防止像素残留/烧屏"
- 情绪：可靠、省心、科技感、护眼

## 视觉方案
- 构图：1:1 方形，主体居中占约 55%，四周留安全边距（适配 launcher 裁切）
- 主体：白色防护盾牌，内嵌手机屏幕轮廓，屏内为排布整齐的发光像素点阵，底部两排像素淡出变透明；盾牌上方一枚小五角星/对勾表示保护生效
- 背景：深蓝紫 → 蓝黑 垂直渐变圆角方形，扁平现代、无投影或轻微内阴影
- 配色：深色背景 + 白色主体 + 一点青绿色（#3EF2A8）强调像素与星标
- 风格：扁平、几何、圆润、干净；禁止渐变过多、禁止拟物金属、禁止杂景
- 文字：无任何文字/字母/品牌字（launcher 图标惯例，名称由系统 label 显示）

## 验收
- 深色/浅色壁纸下剪影清晰
- 缩至 48px 仍能认出盾牌+屏幕
- 无文字、无水印、无多余装饰
