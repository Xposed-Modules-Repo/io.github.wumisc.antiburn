# v3.0 稳定版说明

> 包名 `io.github.wumisc.antiburn`，versionCode **60**，versionName **3.0**。
> 签名证书 SHA-256 `761ef2ac…b993`，与历史版本一致，可直接覆盖安装。
> Obtainment / Obtainium 通过 GitHub Release 的 versionCode 递增识别更新。

## 这一版做了什么

3.0 是**稳定版里程碑**：功能代码沿用 v2.9.7 的定稿实现，本次仅把版本号从 v2.9.7 进阶到 3.0 并出稳定包。此前 v2.9.1 → v2.9.7 的所有改动一并进入本版源码（远端此前停在 v2.9.0）。

## 已知边界与遗留

- **沙箱无真机**：抖音直播间「跳主播离开了」是否随 v2.9.7 恢复路径修复消失、红果/快手/B站真机效果，均需设备侧验证，未在本环境实测。
- **红果付费提示隐藏**：只把浮层设为 `alpha=0 + INVISIBLE`，不解锁付费内容、不替点「0元抢先看 / 立即预约」，可能涉及平台用户协议，详见 `v2.9.6-红果付费提示隐藏.md`。
- **快手点赞/评论/收藏**：本轮零行为改动，等真机日志（`HOOK app=kuaishou` 的 `R=x` / `rgeo/rrej` / `vlive`）再收敛，不猜阈值。
- **一键回退**：恢复路径 `SAFE_RESTORE=false`（逐字节回 v2.9.6）；红果弹窗 `DRAMA_PAYWALL_HIDE=false`。
